# Install (2 minutes)

1. In the repo, on `ui-port/2026-10-09`: `git status`. Commit or stash your
   own work first (`apps/desktop/DESIGN.md` will be replaced).
2. Unzip this kit at the repo root. It adds:
   - `.agent/aro-design-system/{AGENT,ROADMAP,EXTENDING}.md`
   - `docs/adr/0000-template.md`
   - `apps/desktop/DESIGN.md` (replaces; run `git diff` to review)
3. `git add -A && git commit -m "ui-port: add UI-DS agent kit"`.
4. Open your coding agent in the repo and paste `START-PROMPT.md`.
5. At each gate, test the app yourself, then reply "continue" or list changes.
