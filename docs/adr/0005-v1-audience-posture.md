# ADR 0005: v1 audience posture (Public Beta)
Status: accepted
Date / Author: 2026-10-19 / Aro Program (Founder Decision D-5)
Context: Setting expectations around stability, telemetry, defect reporting, and user communication for the initial public release of Aro.
Decision: Launch public v1 as a clearly labeled "Public Beta" with explicit release notes, feedback channels, and known issues documentation.
Alternatives considered:
- General Availability (rejected: premature for v1 with complex multi-process desktop agent architecture).
- Invite-only (rejected: limits community adoption and broad hardware/OS feedback loops).
Impact: UI badging, documentation, support links, crash/feedback reporting, and versioning terminology.
Roadmap slot: P10.5, P16.2.
Acceptance: App UI and documentation clearly reflect Public Beta status without compromising polish or quality.
