# Install (2 minutes)

1. On `ui-port/2026-10-09`: `git status`; commit or stash your own work.
   Finish Phase 8 (design system) through at least Gate B first.
2. Unzip this kit at the repo root. It adds:
   - `.agent/aro-ux-assembly/{AGENT,ROADMAP,FRICTION}.md`
   - `apps/desktop/LAYOUT-UX.md`
3. `git add -A && git commit -m "ui-port: add UX-ASM agent kit"`.
4. Open your coding agent in the repo and paste `START-PROMPT-UX.md`.
5. At each gate, use the app yourself, then reply "continue" or list changes.
